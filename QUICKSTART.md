# Быстрый старт

## Установка

1. **Создайте виртуальное окружение:**
```powershell
py -m venv .venv
.\.venv\Scripts\Activate.ps1
```

2. **Установите зависимости:**
```powershell
pip install -r requirements.txt
```

3. **Установите PyTorch с CUDA:**
Следуйте инструкциям на https://pytorch.org/get-started/locally/

4. **Настройте .env файл:**
```powershell
copy .env.example .env
```
Отредактируйте `.env` и укажите:
- `TELEGRAM_BOT_TOKEN` - токен бота от @BotFather
- `HF_TOKEN` - токен Hugging Face (если модель gated)
- Убедитесь, что пути указывают на диск E:\

## Запуск

### Тестирование базовой функциональности (без LLM):
```powershell
python test_basic.py
```

### Запуск Telegram бота:
```powershell
# Из корневой директории проекта:
python bot/main.py

# Или из любой директории (скрипт автоматически найдёт корень проекта):
cd bot
python main.py
```

**Важно:** При первом запуске AirLLM загрузит и разложит модель по слоям. Это может занять время и потребовать ~15-20 GB свободного места на диске E:\

## Использование

1. Найдите вашего бота в Telegram
2. Отправьте `/start`
3. Используйте `/new` для начала новой игры
4. Выбирайте действия через кнопки
5. Используйте `/save` для сохранения прогресса

## Структура проекта

- `engine/` - игровая механика
- `content/` - контент игры (JSON)
- `llm/` - интеграция с AirLLM
- `bot/` - Telegram бот
- `save/` - система сохранений
- `config/` - конфигурация

## Устранение проблем

**Ошибка "CUDA not available":**
- Убедитесь, что установлен PyTorch с поддержкой CUDA
- Проверьте драйверы NVIDIA

**Ошибка "Model not found":**
- Проверьте интернет-соединение
- Убедитесь, что указан правильный `MODEL_ID` в `.env`
- Если модель gated, укажите `HF_TOKEN`

**Медленная генерация:**
- AirLLM использует layer-wise inference и работает медленно
- Это нормально для данного подхода
- Можно использовать более быструю модель или оптимизировать промпты
