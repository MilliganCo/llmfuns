# Survival Game с AirLLM

Текстовая survival-игра в формате Telegram-бота с LLM-нарратором и детерминированной игровой механикой.

## Описание

Игра представляет собой текстовый survival-симулятор, где игрок должен выживать в постапокалиптическом мире. Каждый ход игрок выбирает действие из предложенных вариантов, а LLM (AirLLM) генерирует атмосферные описания и варианты действий. Вся игровая механика (ресурсы, события, исходы действий) управляется кодом для обеспечения справедливости и баланса.

## Цель игры

Прожить **7 дней** или собрать **3 сигнальные детали** для победы.

## Установка

### 1. Клонирование и настройка окружения

```powershell
# Создание виртуального окружения
py -m venv .venv
.\.venv\Scripts\Activate.ps1

# Установка зависимостей
pip install -r requirements.txt
```

### 2. Установка PyTorch с CUDA

Установите PyTorch с поддержкой CUDA согласно вашей версии драйвера NVIDIA:
https://pytorch.org/get-started/locally/

Проверка CUDA:
```python
python -c "import torch; print(torch.cuda.is_available())"
```

### 3. Настройка переменных окружения

Скопируйте `.env.example` в `.env` и заполните:

```powershell
copy .env.example .env
```

Отредактируйте `.env`:
- `TELEGRAM_BOT_TOKEN` - токен бота от @BotFather
- `HF_TOKEN` - токен Hugging Face (если модель gated)
- Убедитесь, что пути `HF_HOME` и `AIRLLM_LAYERS_PATH` указывают на диск E:\

### 4. Первый запуск модели

При первом запуске AirLLM загрузит и разложит модель по слоям. Это может занять время и потребовать ~15-20 GB свободного места на диске E:\

## Запуск

```powershell
python bot/main.py
```

## Структура проекта

- `engine/` - игровая механика (состояние, действия, события, баланс)
- `content/` - контент игры (локации, предметы, события) в формате JSON
- `llm/` - интеграция с AirLLM (модель, промпты, генерация сцен)
- `bot/` - Telegram бот (handlers, клавиатуры, форматирование)
- `save/` - система сохранений
- `config/` - конфигурация игры и модели
- `data/saves/` - сохранения игроков (создаётся автоматически)

## Игровая механика

### Ресурсы игрока

- **HP** (0-100) - здоровье
- **Голод** (0-100) - растёт со временем
- **Жажда** (0-100) - растёт быстрее голода
- **Тепло** (0-100) - падает от холода/дождя
- **Энергия** (0-100) - падает от действий

### Действия

- Осмотреться
- Собрать ресурсы
- Охота/рыбалка
- Развести костёр
- Поставить укрытие
- Пить/есть
- Отдохнуть/поспать
- Крафт предметов
- Переместиться

### Сохранения

Используйте команды `/save` и `/load` для управления сохранениями.

## Технические детали

- **Модель LLM**: Mistral-7B-Instruct или Qwen-7B-Chat
- **VRAM**: ограничено до ~7GB для RTX 4060 8GB
- **Детерминированность**: RNG с seed для воспроизводимости
- **Безопасность**: строгая валидация действий от LLM
